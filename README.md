# SidSphere

> **Personal Portfolio Website of Sidharth Kumar**

SidSphere is a modern, responsive personal portfolio website designed to showcase **Sidharth Kumar's** skills, education, experience, projects, certificates, awards, and contact. It combines a **code-inspired / terminal aesthetic** with smooth animations, interactive UI elements, and a responsive layout.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/sidhaaarth24/sidsphere.git
```

### 2. Open the Project

```bash
cd sidsphere
```

### 3. Run the Website

This is a static website, so no package installation or build process is required.

Simply open:

```text
index.html
```

in your browser.

For development, you can also use **VS Code Live Server**.

---

## Customization

You can customize the portfolio by editing:

### Personal Information

Edit the content inside:

```text
index.html
```

### Colors & Theme

Modify the CSS variables inside:

```text
style.css
```

For example:

```css
:root {
    --bg: #05080d;
    --bg2: #080d14;
    --text: #e9f3ff;
    --blue: #00aaff;
    --blue2: #0066ff;
}
```

The project is structured around CSS custom properties, making the theme relatively easy to modify.

### Images

Replace the files inside:

```text
images/
```

while keeping the filenames referenced by `index.html`.

## Deployment

The website can be deployed easily using **GitHub Pages**.

### GitHub Pages

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Choose the deployment branch.
6. Save the configuration.
7. GitHub will generate the public website URL.
